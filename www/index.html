Pengaturan AI & Backup Data
🌙 Mode Gelap bertema biru — nyaman di mata saat malam hari.
💡 Format kunci terdeteksi otomatis: Gemini (AIza...), Groq (gsk_...), OpenRouter (sk-or...), OpenAI/DeepSeek (sk-...).
Untuk pencarian musik/video dibutuhkan YouTube Data API Key gratis (1 menit dari Google Cloud Console). Untuk masuk & sync Google dibutuhkan Google Client ID. Unduhan butuh server download (opsional, mis. instance cobalt).
Cara ambil: console.cloud.google.com → buat proyek → APIs & Services → aktifkan YouTube Data API v3 → Credentials → Create API key. Tanpa kunci, kamu tetap bisa menempel link YouTube untuk diputar langsung.
Cara ambil: console.cloud.google.com → APIs & Services → Credentials → Create OAuth client ID → tipe Web application → tambahkan Authorized JavaScript origins: URL aplikasi ini (mis. http://localhost:8081 dan alamat preview kamu).
Unduhan musik/video butuh server proxy kompatibel cobalt (free & self-host: github.com/imputnet/cobalt). Kosongkan untuk menyembunyikan tombol unduh.
Kelola izin notifikasi, kamera, dan lokasi. Tombol lonceng di Beranda juga mengatur notifikasi.
Backup .zip berisi seluruh data & file asli (foto, dokumen, dll) — bukan cuma teks JSON.
